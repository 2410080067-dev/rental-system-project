## 🎯 THREE SIMPLE STEPS

### Step 1️⃣: Setup (5 minutes)
```bash
# Create database
mysql -u root -p
CREATE DATABASE rentaldb;

# Configure backend
Edit: backend/src/main/resources/application.properties
Update: MySQL username/password
```

### Step 2️⃣: Start Backend
```bash
cd backend
mvn spring-boot:run
```
✅ Runs on: **http://localhost:8081/api**

### Step 3️⃣: Start Frontend
```bash
cd frontend/rental-frontend
npm install
npm start
```
✅ Opens: **http://localhost:3000**
